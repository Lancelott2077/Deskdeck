# DeskDeck

A USB macro keypad built on an STM32 Blue Pill, with a Pomodoro timer
and one-press screenshot-to-Claude.

Built as a learning project to get hands-on with GPIO, timer interrupts,
UART, and USB HID on STM32.

## Hardware

- STM32F103C8T6 "Blue Pill"
- ST-Link V2 programmer
- USB-to-TTL adapter (3.3 V)
- 10 push buttons
- Rotary encoder (Phase 2)
- TFT display (Phase 2)
